# Commit hooks

- Hooks can restage tracked files. Editing or staging the next change while a commit is running can pull unrelated edits into that commit.
- Wait for the commit and its hooks to finish before preparing the next change.
- Repository policy: [Git and pull requests](../../AGENTS.md#git-and-pull-requests). Commit workflow: [commit skill](../../.agents/skills/commit/SKILL.md).
