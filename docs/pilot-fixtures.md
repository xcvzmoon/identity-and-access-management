# Phase 10 application fixture results

On 19 November 2026 the application fixtures ran against commit `71b3eb2`, with Node 26.13.0, PostgreSQL 18.6, a loopback Mailpit mailbox, and Playwright Chromium. Each phase used a fresh database in a disposable local cluster. The IdP and console migrations ran under separate schema owners. PostgreSQL reported that each runtime role had schema usage only for its own application. The browser fixtures used a local TLS certificate for the issuer, console, and Reports.

| Check                                | Observed result                                                                                                                                                                                                                               |
| ------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Workspace                            | `vp check`, `vp run typecheck`, and all four workspace builds passed. The default test run passed its enabled tests and skipped nine integration tests. The rows below record the opt-in runs.                                                |
| Invitation signup and password reset | All three invitation tests passed using delivered email and the IdP API on loopback port 56831.                                                                                                                                               |
| OIDC and tenant isolation            | The Reports browser fixture passed at issuer `https://localhost:56820`. It exercised discovery, signing keys, consent, separate installations, and code exchange.                                                                             |
| Live access and IAM sign-out         | Two IdP processes shared issuer `https://localhost:56451`. Reports denied the next request after revocation and after IAM sign-out. An unavailable introspection endpoint yielded HTTP 503 and access resumed when the endpoint recovered.    |
| Console sessions and ingress logs    | At `https://localhost:56471`, the console established its own host-only session, rejected an expired session and handled local and IAM sign-out. The ingress log check passed on a fresh database without emitting its synthetic credentials. |
| Owner recovery                       | The administration and passkey-session tests passed at `https://localhost:56750`, including replacement-owner recovery, its audit event, and session-bound step-up.                                                                           |
| Audit roles and retention            | The audit SQL assertions passed. The purge removed the two expired fixture events and the fixture transaction rolled back.                                                                                                                    |
| Signing keys                         | The PostgreSQL rotation test passed for concurrent publication, activation, overlapping token verification, and rollback to the trusted signer.                                                                                               |

These fixtures used freshly built Node processes. See the [pilot runbook](pilot.md) for deployment checks and the [validation guide](validation.md) for fixture commands.
